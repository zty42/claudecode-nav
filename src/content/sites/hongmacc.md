## 1. 平台概述
**HongMaCC** 是一个专注于为开发者提供企业级 AI API 中转服务的平台。它通过聚合 Claude Code、Codex、Gemini 等全球顶尖 AI 模型，旨在解决国内开发者在网络连接、支付门槛和 API 响应速度方面遇到的痛点。

## 2. 核心服务优势

### 🚀 极致性能与稳定性
* **国内直连**：无需配置复杂的网络环境（如 VPN 或代理），通过国内优化线路直接访问。
* **毫秒级响应**：通过智能路由优化和全球节点部署，平均延迟 **<50ms**。
* **高可用架构**：采用分布式架构与自动故障转移机制，保障 **99.9%** 的服务可用性 (SLA)。
* **全球覆盖**：拥有 **20+** 全球服务节点，确保无论身处何地都能获得稳定的连接。

### 🛠️ 无缝技术集成
* **全模型支持**：聚合了 Claude Code、Codex、Gemini 等主流编程辅助模型。
* **完美兼容主流工具**：
    * **编辑器支持**：深度适配 **Cursor**、**VSCode** 等 AI 编程工具。
    * **API 兼容**：完全兼容 OpenAI 官方 API 格式（`chat/completions`），仅需修改 Base URL 即可无缝迁移。
* **零代码侵入**：开发者只需替换 API 地址，无需修改现有业务代码逻辑。

### 🛡️ 安全保障
* **企业级防护**：提供企业级的数据安全标准。
* **加密传输**：全程数据加密，保障代码隐私与数据安全。
* **专业支持**：提供 7x24 小时稳定运行保障及专属客服支持。

## 3. 定价与付费方案

HongMaCC 采用灵活的**按量付费**模式，降低了用户的准入门槛。

### 💰 计费模式
* **按量付费 (Pay-as-you-go)**：用户仅需为实际消耗的 Token 付费，拒绝资源浪费。
* **无隐形门槛**：
    * 无需绑定海外信用卡。
    * 无需预付高额的订阅费用。

### 🏢 套餐与费率
* **基础费率**：具体模型的倍率（Token Price）可在注册登录后的**控制台**中查看，平台宣称价格亲民。
* **企业定制**：针对高并发或特殊需求的企业团队，提供定制化套餐服务。
